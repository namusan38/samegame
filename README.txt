============================================================
 さめがめローグ  README
============================================================

■ 概要
同じ色のブロックを消して、目標スコアを目指すローグライク風さめがめです。
ステージをクリアするたびに強化(アップグレード)を1つ選び、
ゲームオーバーまでにどこまで進めるかを競います。
ストーリーモードでは、マーベリック・ダンヒルと香の物語が全20ステージ(4章)で進みます。

・1ファイル完結のHTMLゲームです(外部ライブラリ不使用)
・iPhone(Safari)での操作を前提に作っています
・盤面は 10列 × 12行


■ 基本ルール
1. 同じ色が2個以上つながった塊をタップすると選択されます
2. もう一度タップすると消えます(大きい塊ほど高得点)
3. 手数内に目標スコアに到達するか、全消しでステージクリアです
4. クリアすると強化を3つの中から1つ選べます
5. 手数が0になる、または消せるものがなくなるとゲームオーバーです

【得点】
・n個消し = (n-2)² 点(2個は0点、3個は1点、10個は64点)
・全消し +100点
・残りブロックが10個以下でクリア: (11-残り個数)×10点 のボーナス
・目標スコア = (40 + 25×ステージ + 6×ステージ²) × 難易度の倍率

【手数】
・基本は15手(難易度と強化で増減)
・ミッションを達成すると +2手


■ 難易度
  簡単   目標70%  手数+4  ハンマー+1  4色  パイプあり
  普通   標準               5色  パイプあり(パイプだけではクリア不可)
  難しい 目標140% 手数-3  ハンマー-1  7色  パイプあり
  激ムズ 目標180% 手数-5  ハンマー-1  8色  パイプなし(強化で入手)

※ ベストステージとランキングは、難易度ごと・モードごとに別々に記録されます


■ 特別なブロック・操作
【🔨 ハンマー】
手数を使わず、好きなブロックを1個消せます(使える回数はステージごと)。
ボタンを押してから、消したいブロックをタップします。

【パイプ】(絵柄つきのブロック)
タップすると、盤面にある同じ色のブロックをすべて消せます(+3点/個)。
ステージ開始時に、どの色がパイプかがメッセージで表示されます。

【💣 ボム】(2ステージ目から出現)
タップすると、周囲3×3マスを消します(+4点/個)。

【🎯 ミッション】
「N個以上の塊をK回消す」が各ステージに出ます。達成すると手数+2です。


■ 強化(クリアごとに3択)
  手数 +3           毎ステージの手数が3増える
  色が1つ減る       ブロックの色数-1(最低3色)
  得点 +25%         すべての得点が増える(重ねがけは加算)
  ちびボーナス      2個消しで+4点
  ドカン            7個以上消しで+15点
  ハンマー +1       毎ステージ、ハンマーが1回増える
  トリオボーナス    3個消しで+6点
  手数の貯金        クリア時、残り手数1つにつき+8点
  ロケットスタート  各ステージを+25点の状態で始める
  リターン          8個以上消すと手数が1戻る
  ビッグハンマー    ハンマーが十字(5マス)を消す
  お掃除            各ステージ開始時、ブロックが最大8個消えている
  パイプ追加        次のステージからパイプが1個増える(重ねがけ可)


■ ストーリーモード
開始時に「ストーリーモード」を選びます。全20ステージで、5ステージごとに1章です。

【登場人物】
・マーベリック・ダンヒル … 主人公。元・記憶調律師。普段はおちゃらけているが、やる時はやる。美女に弱い
・香(かおり)           … 依頼人兼監視役。ボーイッシュでしっかり者。たまにおっちょこちょい。
                            マーベリックの暴走には100tハンマーで制裁する
・ライバル               … 虚無の幹部。第3章のボス

【章立て】
  第1章 出会い     〜海の星〜     ボス: 虚無の影   (5面)
  第2章 共闘       〜森の星〜     ボス: 森の蔦     (10面)
  第3章 すれ違い   〜街の星〜     ボス: ライバル   (15面)
  第4章 決戦       〜虚無の核〜   ボス: 虚無の核   (20面)

・章の最初と、ボス戦の前後に会話シーンが入ります(「次へ」で進行)
・通常ステージでは、盤面の下にマーベリックのモノローグが1行出ます
・ハンマー使用時にも香とマーベリックの掛け合いが出ます
  (10%の確率で、香のハンマーが狙いからずれる「おっちょこちょい」あり)

【💃 美女ブロック】(ボス戦以外のステージで出現)
・🔨ハンマーでしか消せません(塊消し・パイプ・ボムでは消えません)
・盤面にある間は、マーベリックがデレデレして手数を削られます
    普通・難しい: 3手ごとに手数-1 / 激ムズ: 2手ごとに手数-1
・ハンマーで消すと、手数+2 になり、香の制裁が入って正気に戻ります
・美女が出るステージでは、ハンマーが+1個配られます
・盤面がピンク色になり、マーベリックの台詞がデレデレ調になります
・出現率: 簡単=出ない / 普通=約33% / 難しい=約50% / 激ムズ=毎ステージ

【⚔ ボス戦】(5・10・15・20面)
・手数が増え、ハンマーも+1個配られます。美女ブロックは出ません
    1章: 手数+2  目標スコア 通常
    2章: 手数+3  目標スコア +10%
    3章: 手数+2  目標スコア +15%
    4章: 手数+4  目標スコア +25%
・ボスごとのルール
    1章 虚無の影 … 3手ごとに、ブロックが1個「虚無」(🌑)になる。🔨でのみ消せる
    2章 森の蔦   … 4手ごとに、各列に蔦(ブロック)が降ってくる
    3章 ライバル … 1色が「忘却」(灰色の「？」)になり、塊消しができなくなる。
                    5手ごとに別の色へ移る(ボム・パイプ・🔨なら消せる)
    4章 虚無の核 … 上の3つが全部起きる(虚無は4手ごと、蔦は5手ごと、忘却は6手ごと)
・ボス戦・第4章・残り手数3以下のときは「本気モード」になります
  (盤面が暗くなり、BGMが自動選択のときはダークな曲に切り替わります)

【エンディング】
・20面のボスを倒すとエンディングです(通常 / 真)
・真エンディングの条件: ミッション達成12回以上、または 全消し3回以上
・エンディング後は「エンドレス」で続けられます(21面以降、ボスなし)

【ゲームオーバー】
・ストーリーモードでは、マーベリックのハードボイルドな台詞が出ます
  (20面のボスで負けたときだけ専用の台詞)


■ ランキング
・ゲームオーバー時とエンディング時に、ニックネームを入れて登録できます
・共有ランキング(みんなのランキング)は、claude.aiにログインして
  公開ページで遊んでいる場合に使えます
・使えない場合は、その端末の記録(上位5件)が表示されます
・難易度ごと、通常/ストーリーごとに別のランキングです
・スコアはブラウザ側で計算しているため、改ざんを完全には防げません


■ 音
・🔊 効果音のオン/オフ
・🎵 BGMのオン/オフ(画面を最初に1回タップすると流れ始めます)
・♪ BGMの切り替え: 自動 / ダーク / チップ / ローファイ / サイバー / タイトル
  (自動は、ステージが進むと曲が変わります)


■ 開発メモ(盤面の内部値)
  -1      空き
  0〜7    色ブロック(8色)
  10〜17  パイプ(色+10)
  20      ボム
  30      美女ブロック
  40      虚無ブロック

・ストーリー用のデータ(台詞・章・ボス倍率など)は、スクリプト冒頭の
  「ストーリーモード用データ」にまとめてあります
・主な設定値:
    ボス手数ボーナス  BBONUS = [2,3,2,4]
    ボス目標倍率      BMUL   = [1,1.1,1.15,1.25]
    美女の出現率      start() 内(普通 .33 / 難しい .5 / 激ムズ 1)
    美女の放置ペナルティ  spend() 内(3手ごと、激ムズは2手ごと)
    真エンディング条件    ending() 内(mcnt>=12 || acnt>=3)
・ブラウザの保存データ(localStorage)のキー:
    sgr_diff / sgr_story / sgr_best* / sgr_rank / sgr_name / sgr_mute / sgr_bgm / sgr_bm


■ 注意
・ストーリーの設定やセリフには、既存作品へのオマージュ(100tハンマーなど)が含まれます。
  広く公開する場合は、呼び名や設定を変えるかどうか検討してください
